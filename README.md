# 🤖 ربات چندمنظوره‌ی دانلود و موسیقی (تلگرام)

رباتی حرفه‌ای که با یک منوی ساده، از **اینستاگرام، فیسبوک و یوتیوب** دانلود می‌کند و
**موسیقی** را هم با نام پیدا می‌کند و هم از روی یک کلیپ صوتی تشخیص می‌دهد.

## ✨ امکانات

- 📷 **اینستاگرام** / 📘 **فیسبوک** / ▶️ **یوتیوب** — دانلود ویدیو و عکس (با `yt-dlp`)
- 🎵 **موسیقی:**
  - جستجو با نام آهنگ/خواننده → ارسال فایل MP3
  - تشخیص آهنگ از روی پیام صوتی/ویدیو (مثل Shazam) → سپس ارسال MP3
- 🧭 **منوی انتخاب سرویس** (اول انتخاب، بعد ارسال لینک) + تشخیص خودکار سرویس از روی لینک
- 📉 **انتخاب خودکار بهترین کیفیت زیر ۵۰ مگابایت** (سقف ربات‌های تلگرام)
- 🗑️ **حذف کامل فایل‌ها بلافاصله بعد از ارسال** — مصرف حافظه ≈ صفر
- ⚡ **پردازش همزمان** (`concurrent_updates`) برای تعداد کاربر بالا
- ☁️ اجرا در دو حالت `polling` و `webhook`

## 🚀 دیپلوی رایگان روی Render (پیشنهادی)

پروژه با **Docker** اجرا می‌شود تا `ffmpeg` (برای تبدیل صدا و ادغام ویدیو) در دسترس باشد.

1. وارد <https://render.com> شوید و با GitHub لاگین کنید.
2. **New → Blueprint** را بزنید و این ریپازیتوری را انتخاب کنید (فایل `.render.yaml` آماده است).
3. متغیر `BOT_TOKEN` را وارد کنید (از [@BotFather](https://t.me/BotFather)).
4. **Apply** بزنید. چند دقیقه بعد ربات فعال است.

> Render به‌طور خودکار `RENDER_EXTERNAL_URL` را ست می‌کند و ربات از webhook استفاده
> می‌کند؛ نیازی به تنظیم دستی نیست. در پلن رایگان بعد از بی‌کاری سرویس می‌خوابد و با
> اولین پیام دوباره بیدار می‌شود.

### گزینه‌ی همیشه‌روشن: Koyeb / Fly.io
همان `Dockerfile` را می‌پذیرند و همیشه روشن می‌مانند (برای polling ایده‌آل). فقط
`BOT_TOKEN` را ست کنید.

## 🖥️ اجرای محلی

```bash
pip install -r requirements.txt      # به ffmpeg هم نیاز دارید (apt install ffmpeg)
export BOT_TOKEN="توکن-شما"
python bot.py
```

## 🛠 پنل مدیریت

۱. آی‌دی عددی خود را با دستور **/id** در ربات ببینید.
۲. آن را در متغیر محیطی **`ADMIN_IDS`** بگذارید (چند ادمین با کاما).
۳. در ربات **/admin** را بزنید تا پنل باز شود.

از داخل پنل می‌توانید **داینامیک** تنظیم کنید:
- 🔒 **قفل عضویت اجباری** — کاربر باید اول در کانال‌ها عضو شود تا ربات کار کند
  (ربات باید در آن کانال‌ها **ادمین** باشد).
- 📢 **مدیریت کانال‌ها** — افزودن/حذف کانال‌های عضویت اجباری
- 🧩 **سرویس‌ها** — روشن/خاموش کردن اینستاگرام/فیسبوک/یوتیوب/موسیقی
- 🚧 **حالت تعمیر** — موقتاً ربات را برای همه (جز ادمین‌ها) ببندید
- ✉️ **پیام همگانی** — ارسال پیام به همه‌ی کاربران
- ✏️ **پیام خوش‌آمد** — تغییر متن خوش‌آمد
- 📊 **آمار** — تعداد کاربران و وضعیت تنظیمات

> نکته‌ی ماندگاری: تنظیمات در `DATA_DIR` ذخیره می‌شوند. روی **Render رایگان** دیسک
> دائمی نیست و با هر ری‌دیپلوی ریست می‌شود؛ به همین دلیل مقادیر مهم (ادمین‌ها،
> کانال‌ها، روشن بودن قفل) از **متغیرهای محیطی** هم بذر (seed) می‌شوند تا پایدار
> بمانند. برای ماندگاری کامل تغییرات پنل، `DATA_DIR` را روی یک **دیسک دائمی**
> (Koyeb/Fly volume یا دیسک پولی Render) تنظیم کنید.

## 🔑 متغیرهای محیطی

| متغیر | الزامی | توضیح |
|-------|--------|-------|
| `BOT_TOKEN` | ✅ | توکن ربات از BotFather |
| `ADMIN_IDS` | ➖ | آی‌دی عددی ادمین‌ها (با کاما). برای پنل مدیریت لازم است. |
| `FORCE_JOIN` | ❌ | `true/false` — قفل عضویت اولیه (از پنل هم قابل تغییر) |
| `REQUIRED_CHANNELS` | ❌ | کانال‌های اجباری، مثل `@ch1,@ch2` |
| `DATA_DIR` | ❌ | مسیر ذخیره‌ی تنظیمات (پیش‌فرض `data`) |
| `RATE_LIMIT_PER_MIN` | ❌ | حداکثر درخواست هر کاربر در دقیقه (پیش‌فرض ۱۵) |
| `MAX_CONCURRENT` | ❌ | حداکثر دانلود همزمان روی کل سرور (پیش‌فرض ۴) |
| `DOWNLOAD_RETRIES` | ❌ | تعداد تلاش مجدد روی خطای موقت (پیش‌فرض ۲) |
| `WEBHOOK_URL` | ❌ | فقط حالت webhook؛ روی Render خودکار |
| `PORT` | ❌ | پورت webhook |
| `COOKIES_FILE` | ❌ | مسیر فایل کوکی برای محتوای محدودشده‌ی اینستاگرام/فیسبوک |

## ⚠️ نکات

- **حجم ۵۰MB:** سقف آپلود ربات‌های تلگرام است. ربات خودکار کیفیت را کم می‌کند تا زیر این حد
  بماند؛ اگر حتی کم‌کیفیت‌ترین نسخه هم بزرگ‌تر بود، پیام می‌دهد.
- **محدودیت پلتفرم‌ها:** گاهی اینستاگرام/یوتیوب IP سرورهای ابری را محدود می‌کنند. در این
  صورت یک فایل کوکی (`COOKIES_FILE`) تنظیم کنید.
- **مقیاس ۱۰۰٬۰۰۰ کاربر:** کد به‌صورت async و همزمان نوشته شده و حافظه را آزاد نگه می‌دارد،
  اما برای بار واقعیِ بسیار سنگین به هاست پولی (worker همیشه‌روشن + پهنای‌باند بیشتر) و در صورت
  نیاز صف پردازش (queue) نیاز دارید؛ پلن رایگان برای حجم بالا محدودیت منابع دارد.
- **امنیت توکن:** توکنی که قبلاً در کد بود در تاریخچه‌ی git مانده؛ حتماً با `/revoke` در
  BotFather یک توکن تازه بسازید و فقط در `BOT_TOKEN` قرار دهید.

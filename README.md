# 🤖 ربات دانلود اینستاگرام برای تلگرام

رباتی که لینک **پست**، **ریلز** یا **IGTV** اینستاگرام را می‌گیرد و فایل آن را در تلگرام می‌فرستد.

## ✨ امکانات

- ✅ دانلود پست، ریلز، عکس و ویدیو
- ✅ پشتیبانی از پست‌های چندتایی (کاروسل)
- ✅ **حذف خودکار فایل‌ها بعد از ارسال** — مصرف حافظه‌ی هاست تقریباً صفر
- ✅ اجرا در دو حالت: `polling` (لوکال/ورکر) و `webhook` (هاست وب رایگان)
- ✅ توکن از متغیر محیطی (امن)
- ✅ مدیریت خطا، لاگ‌گیری، و بررسی محدودیت حجم ۵۰ مگابایتی تلگرام

---

## 🔧 اجرای محلی (Local)

```bash
pip install -r requirements.txt
export BOT_TOKEN="توکن-شما-از-BotFather"
python bot.py
```

بدون `WEBHOOK_URL`، ربات به‌صورت **polling** اجرا می‌شود (برای تست عالی است).

---

## ☁️ هاست رایگان

ربات هر دو حالت را پشتیبانی می‌کند. یکی از گزینه‌های زیر را انتخاب کنید:

### گزینه ۱ — Render (پیشنهادی، حالت webhook) 🟢

فایل `.render.yaml` از قبل آماده است.

1. وارد <https://render.com> شوید و با GitHub لاگین کنید.
2. **New → Blueprint** را بزنید و این ریپازیتوری را انتخاب کنید.
3. در بخش Environment، متغیر `BOT_TOKEN` را وارد کنید.
4. Deploy کنید.

> Render به‌طور خودکار `RENDER_EXTERNAL_URL` را تنظیم می‌کند و ربات از آن برای
> webhook استفاده می‌کند — نیازی به تنظیم دستی `WEBHOOK_URL` نیست.
>
> نکته: پلن رایگان Render بعد از ۱۵ دقیقه بی‌کاری خاموش می‌شود؛ اما چون از
> webhook استفاده می‌کنیم، اولین پیام کاربر سرویس را دوباره بیدار می‌کند
> (فقط اولین پیام کمی با تأخیر پاسخ می‌گیرد).

### گزینه ۲ — Koyeb یا Fly.io (حالت polling با Docker) 🟢

فایل `Dockerfile` آماده است. کافیست ریپو را متصل کرده و فقط متغیر `BOT_TOKEN`
را تنظیم کنید. این هاست‌ها همیشه روشن می‌مانند و برای polling ایده‌آل‌اند.

### گزینه ۳ — Railway 🟡

`Procfile` آماده است. متغیر `BOT_TOKEN` را ست کنید. (اعتبار رایگان محدود.)

## 🔑 متغیرهای محیطی

| متغیر | الزامی | توضیح |
|-------|--------|-------|
| `BOT_TOKEN` | ✅ | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `WEBHOOK_URL` | ❌ | فقط برای حالت webhook. روی Render خودکار است. |
| `PORT` | ❌ | پورت webhook (هاست معمولاً خودش تنظیم می‌کند). |
| `IG_USERNAME` / `IG_PASSWORD` | ❌ | ورود اختیاری به اینستاگرام برای کاهش خطای rate-limit. |

نمونه در فایل [`.env.example`](./.env.example) موجود است.

---

## ⚠️ نکات مهم

- **فقط پست‌های عمومی (public)** قابل دانلود هستند.
- اینستاگرام گاهی IP سرورهای ابری را محدود می‌کند. در این صورت متغیرهای
  `IG_USERNAME` و `IG_PASSWORD` را تنظیم کنید تا ربات با نشست ورود کار کند.
- توکنی که قبلاً داخل کد بود در تاریخچه‌ی git باقی مانده؛ **حتماً از BotFather یک
  توکن جدید بسازید** (`/revoke`) و آن را فقط در متغیر محیطی `BOT_TOKEN` قرار دهید.
